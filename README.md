# Ghibli Portfolio

Portfolio website dengan tema Studio Ghibli, dibangun dengan Next.js.

## Fitur

- Landing page dengan desain bergaya Ghibli
- Blog dengan sistem manajemen post
- Admin panel untuk membuat, mengedit, dan menghapus post
- Autentikasi admin

## Menjalankan di lokal

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser.

## Tech Stack

- [Next.js](https://nextjs.org) — App Router
- Vanilla CSS
